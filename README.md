# 🏹 Сундучный Вор: Тёмное Фэнтези

Браузерная кликер-игра в стиле Diablo/Bloodborne с готической графикой, PWA-установкой на Android/iOS/ПК и полной офлайн-работой.

![Иконка](public/icon-512.png)

## 🎮 Что в игре

- **🏹 Кликер** — души чумного воришку демоническим луком (AI-портрет 1024×1024)
- **📦 Сундуки** — 10 типов из 3 AI-картинок (железо/золото/проклятый) + CSS-фильтры, искры от ключа, пульсация
- **🗝 Ключи** — 5 редкостей с зажимом для открытия сундуков
- **⚔ Лут** — 1000 предметов 7 редкостей (серый/зелёный/синий/фиолетовый/оранжевый/красный/золотой)
- **🛡 Герой** — готический силуэт в доспехах с 16 ячейками экипировки
- **💀 Авто-бой** — 4 врага (чумной мертвец/скелет/гаргулья/демон), боссы каждые 25 убийств, элиты 12%, частицы крови, тряска экрана
- **⚡ Навыки** — 5 навыков героя (Мощный удар/Вампиризм/Крит/Цепная молния/Массовая атака), открываются на ур. 5/10/15/20/25
- **🎩 Сеты экипировки** — 8 сетов с бонусами 2/4/6 предметов
- **🏛 Крафт/Алтарь** — 5 одинаковых → 1 следующей редкости + жертва лута за удачу
- **📜 Достижения** — 16 шт с авто-прогрессом
- **📅 Дейлики** — 3 случайных в день, сброс в 00:00
- **🏰 Подземелья** — 10 этажей с ×1.5 HP за этаж
- **🎨 Графика** — 8 AI-сгенерированных фонов + готическая UI-палитра

## 🚀 Установка и запуск

```bash
# 1. Установить зависимости
bun install

# 2. Запустить dev-сервер
bun run dev

# 3. Открыть http://localhost:3000
```

### Сборка для продакшена

```bash
bun run build
bun run start
```

## 📱 Установка как PWA (Android/iOS/ПК)

Игра — это Progressive Web App, устанавливается как нативное приложение:

- **Android (Chrome):** открой сайт → меню (⋮) → «Установить приложение»
- **iPhone (Safari):** открой сайт → Поделиться ↗ → «На экран Домой» → «Добавить»
- **ПК (Chrome/Edge):** иконка ⊕ в адресной строке → «Установить»

После установки: иконка на рабочем столе, fullscreen, работает офлайн (service worker кеширует ресурсы).

## 🏗 Технологии

- **Next.js 16** + App Router + TypeScript
- **Tailwind CSS 4** + shadcn/ui
- **Zustand** + persist middleware (состояние в localStorage)
- **Framer Motion** (анимации)
- **PWA**: manifest.webmanifest + sw.js (service worker) + 4 иконки

## 🎨 Сохранение прогресса

Прогресс хранится в `localStorage` под ключом `chest-thief-game-v3`. Включает:
- Ключи, деньги, выбранный ключ
- Буст удачи (если активен)
- Инвентарь лута
- Надетую экипировку
- Состояние боя (уровень, XP, враги)
- Достижения (claimed статус)
- Дейлики (дата, прогресс, claimed)
- Статистику

Кнопка «СБРОС» в правом верхнем углу очищает прогресс.
